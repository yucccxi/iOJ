# iOJ 前端接口文档（v1）

本文件面向前端开发：只说明接口行为、参数含义和字段含义，不涉及服务端实现。
所有接口都以 `/api/v1` 为前缀；示例中的 id、时间仅为示意。

文档按章节拆分，每个章节一个文件，可单独打开或在目录里跳转。

## 维护约定

- 接口行为有变化时，先改本目录下对应的章节文件，再改实现。
- 新增/删除接口时同步更新「目录」、`docs/README.md` 的索引，以及 `09-appendix.md` 里的「页面与接口对照」。
- 章节文件内的相对链接：同级文件直接写文件名，跨目录用 `../`（例如判题器指南指向 `../special-judge.md`）。
